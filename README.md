# Life

공부·돈·취미·일기·AI 를 한곳에서 관리하는 생활 도우미 (한국어, 폰·PC). 메인 화면에서 영역을 고르고, 「공부」에는 문제집·과외 숙제·영단어·오답·시험·성적·공부 시간 등이 모두 들어 있어요.

- **메인**(`#/`): 영역마다 오늘·이번 주 요약, 날씨, 잠·아침 컨디션, 달력·한 주 계획·통계·하루 마감·AI 코치 바로가기
- **농구**(취미 › 농구, `#/basketball`): 농구 기록(경기 승패·득점·리바운드·어시스트와 연습, 2점·3점·자유투 성공률), 농구 연습(드릴), 슛 분석, NBA(경기·순위·로스터·선수). 예전 운동 주소 `#/fitness` 는 취미·농구로 넘어간다. 걷기·달리기 같은 다른 운동은 「하루 마감」에서 오늘 한 것만 적는다
- **돈**(`#/money`): 쓴 돈·들어온 돈, 분류별, 한 달 예산과 남은 날 하루 몫, 달별 흐름, 모으기 목표, **고정 지출·수입**(매일·매주·매달·매년 자동 기록)
- **취미**(`#/hobby`): 취미와 한 시간, 독서, 농구, 영화, 게임(게임 시간·롤 전적·롤 챔피언·롤 실시간·Steam), 음악(가진 음반·사고 싶은 음반·들은 기록), 여행(가 볼 곳·다녀온 곳·지도·여행 기록), 위시리스트
- **AI**(`#/ai`): 문제 풀이 대화 (사진 넣기·모델 고르기, 대화는 이 기기에만 글로 저장)
- **메뉴**: 영역(메인·공부·돈·취미·일기·AI)을 누르면 메인 대신 그 영역의 칸들이 왼쪽(폰은 아래)에 나온다. 위의 돋보기(또는 `/` 키)로 모든 기록 검색.
- **영화**(`#/movies`): 1월 1일 알림에서 열리는 시상식 화면, 극장가·내 영화(본 영화·보고 싶어요·시상식)·찾기·추천 4칸, 본 곳(일반 영화관·아이맥스·스크린X·집·OTT 등)·태그·또 본 기록, 보고 싶어요에 담은 영화 개봉 알림, 1990년~ 영화 목록(단편·성인물 포함)을 서버에 받아 두고(KOBIS) 제목·감독 검색과 장르·나라·연도·유형 거르기, 내 별점이나 보고 싶은 것을 쓰면 AI 추천(목록에서 확인된 영화만), 넷플릭스·Apple TV 등 OTT 표시(TMDB, 비밀값 `TMDB_KEY` 필요), **극장가**(어제 박스오피스·90일 안 개봉 예정, 영화진흥위원회 KOBIS 오픈 API. 바로 「보고 싶어요」·「봤어요」), 본 영화(별점 0.5 단위·한줄 감상평·긴 리뷰·어디서, 별점 분포), 보고 싶은 영화와 개봉일 D-day
- **일기**(`#/diary`): 하루 하나, 기분, 달력에 기분, 찾기, 꿈 모아 보기, 양식, 이번 달 하이라이트, 한 해 결산
- **통계**(`#/week`): 이번 주·이번 달·AI 코치·이것저것, 영역별(공부·성적·운동·취미·돈·올해)
- **공부**(`#/study`): 아래 전부

## 실행

```bash
npm install
npm run dev        # 개발 서버 (같은 와이파이의 폰에서도 접속 가능)
npm test           # 계산 규칙·보안 시험
npx wrangler dev   # 빌드한 사이트 + 로그인 서버를 이 컴퓨터에서 (npm run build 먼저)
npm run build      # 배포용 빌드 (dist)
```

## 되는 것

- **시험**: 시험 날 + 과목별 시험 날·시험 범위(한 줄씩 체크), 학교 진도 기록. 가장 가까운 시험은 오늘 화면 맨 위에 D-day 로 크게
- **오늘**: 시험 D-day, 과외 숙제, 문제집 오늘 분량, 영단어, 복습, 할 일·습관을 한 화면에. 체크 뒤 「틀린 번호」를 쓰면 오답 노트로
- **문제집 계획**: 목차를 붙여 넣거나(목차 사진 글자 인식도 가능) 시험·마감일을 정하면 하루에 풀 쪽을 나눠 줌. 쉬는 요일·빼는 날짜·과외 날 줄이기, 밀리면 남은 날에 자동으로 다시 나눔, 오늘 분량은 오늘 동안 고정, 너무 많아지면 경고, 달력
- **과외 숙제**: 수업 요일·휴강·보강 → 숙제 마감은 자동으로 다음 수업일, 숙제 쪽은 문제집 계획에서 빠지고 풀면 문제집 진도에도 반영, 질문 메모
- **영단어**: 단어장(Day 계획)·단어 시험(이틀 전까지 새 단어, 전날 전체 복습)·모르는 단어 모음. 단어장 PDF(기기 안에서 PDF.js 로 읽음, 스캔 PDF 는 글자 인식)·붙여넣기·사진으로 넣기, 카드(누르면 뒤집혀 뜻, 왼쪽으로 밀면 모른다·빨강, 오른쪽은 안다·초록)·객관식(틀린 보기는 내가 넣은 다른 단어의 뜻에서만)
- **복습**: 오답 노트(사진, 틀린 이유 통계)·암기 카드, 1·3·7·14·30일 간격 상자
- **기록**: 뽀모도로·스톱워치(시작 시각으로 계산해 새로고침해도 맞음), 주간·과목별·최근 4주
- **할 일·습관**: 마감·⭐ 오늘 꼭, 요일별 습관과 연속 일수
- **로그인**(선택): 아이디·비밀번호(이메일 없음). 로그인하면 폰·PC 동기화, 아니면 이 기기에만 저장
  - 계정: 닉네임·비밀번호 바꾸기, 모든 기기에서 로그아웃, 계정 지우기, 로그아웃할 때 이 기기 자료 지우기
- **시험·성적**: 시험 여러 개, 하루 시험(모의고사·수능)과 여러 날 시험(내신: 날짜별 시험 과목), 과목 시험 날은 계획·D-day 에 반영. 지난 성적(내신: 원점수·평균·등급, 모의고사: 원점수·표준점수·백분위·등급)과 과목별 흐름 그래프, 시험 전 4주 공부 시간 비교
- **공부 시간 분석**(기록): 하루 공부 시간 직접 넣기(과목 없이도), 날짜별·주별·요일별·과목별 그래프, 앞 기간과 비교, 연속 공부한 날
- **형광펜 단어**: 단어 넣기 → 「형광펜 사진」: 사진에서 형광펜으로 칠한 영어 단어만 골라(기기 안 글자 인식 + 색 판단) 단어 목록으로, 뜻은 AI 로 채우기(로그인)
- **번역**(메뉴 칸): 한국어 ↔ 영어. 낱말·짧은 말은 사전처럼(품사별 뜻·예문), 글은 자연스럽게, 「직역도 함께」로 의역·직역. 듣기·복사·「모르는 단어 모음」에 넣기. Workers AI `@cf/openai/gpt-oss-120b`(무료 플랜에서 쓸 수 있는 가장 큰 모델), 실패하면 `@cf/google/gemma-4-26b-a4b-it`. 무료 한도(하루 10,000 뉴런)를 지키려고 로그인한 사람만·한 번에 2,000자·한 사람 10분 30번·하루 300번까지
- **예습**: 수업 날·예습할 곳·궁금한 점, 오늘 화면에 오늘·내일 수업 예습, 수업 뒤 이해했는지 체크 → 헷갈린 것은 「다시 볼 것」
- **시험 메뉴**(공부 › 시험): 왼쪽(폰은 아래) 메뉴에 시험 · 수행평가 · 성적 · 내신 목표 · 목표 대학 · 채점
- **목표 대학**(`#/exams/univ`): 대학 · 학과마다 내신 목표 평균 등급, 모의고사 과목별 목표 등급 · 백분위를 직접 넣으면 지금 성적(내신 등급 단순 평균 · 과목마다 최근 모의고사)과 차이. 합격선 자료는 넣지 않는다
- **채점**(`#/exams/check`): 정답(붙여 쓰면 한 글자가 한 문제, 주관식은 띄어 쓰기) · 배점(선택) · 내 답(1~5 누르기 또는 글로 한꺼번에) → 점수 · 맞은 수 · 틀린 번호. 「기출·모의고사 풀이로 저장」하면 점수 · 틀린 번호가 채워진 넣기 창이 열리고, 틀린 번호는 오답 노트로
- **성적표 사진으로 채우기**(성적 → 성적 넣기, 로그인): 내신 · 모의고사 성적표 사진을 AI(Gemini)가 읽어 종류 · 시험 이름 · 날짜 · 과목별 원점수 · 등급 · 평균 · 표준점수 · 백분위를 채운다 (적힌 값만, 확인 뒤 저장)
- **잘 시간 알림**(설정 → 알림, 로그인): 다음 날 일어날 시각(평일 · 주말) − 잠 목표 = 잘 시각, 그보다 0 · 15 · 30 · 60분 먼저 휴대폰 알림
- **모의고사 보기 · 문항별 시간**(기록 → 모의고사 보기): 「문항별 시간 재기」를 켜면 시험 화면에 번호판이 나와 문제를 옮길 때마다 번호를 누르고, 끝나면 오래 걸린 번호를 보여 준다 (풀이 기록에도 저장)
- **영어 듣기 자동 재생**: 모의고사 보기에서 영어 듣기 음원 파일을 이 기기에 넣어 두면, 영어 영역을 시작할 때 함께 튼다 (듣기 동안 시험장 소리는 줄임)
- **단어 듣기**(단어 → 🎧 듣기): 단어 → 뜻을 차례로 읽어 준다 (기기 읽어 주기, 섞기 · 두 번 · 빠르기 · 사이 시간)
- **공부 리포트**(통계 → 이번 주): 한 주 공부 시간 · 과목별 · 공부한 날 · 시험 진도 · 최근 성적 · 오답 · 수행평가를 그림 한 장으로 (공유 · 내려받기)
- **약 · 영양제**(할 일 · 습관, 메인): 먹는 시각마다 알림, 체크하면 그날 알림은 빠진다
- **집중 화면 유튜브**: 링크를 넣으면 youtube-nocookie 삽입 플레이어로 튼다 (음원을 내려받지 않음), 넣은 링크는 이름 붙여 저장
- **시장**(`#/market`): 공부 10분 · 습관 · 할 일 · 오답 해결로 포인트(기록에서 계산)를 모아 내가 정한 보상과 바꾼다. 상점 · 지갑 · 규칙
- **영어 어법**(저장소 › 영어 어법): 어법 유형마다 확인할 것 · 예, 영어 오답에 유형을 달면 유형별로 모아 보기
- **일정 날 비 예보 알림**(설정 → 알림): 달력 일정 날 비 · 눈 올 확률 50% 이상이면 전날 21시 (Open-Meteo)
- **방학 계획**(할 일 · 습관) · **시험 끝나고 할 것**(시험): 방학 하루 목표 지킨 날 · 할 것 체크, 시험 끝나는 날 18시 알림
- **하루 마감**: 휴대폰 사용 시간(직접 적기) · 계획을 못 지킨 이유 → 기록 화면 통계
- **교과서 PDF → 백지 복습**(저장소 › 백지 복습, 로그인): 과목별 교과서 PDF(이 기기 저장)와 시험 범위의 쪽(「교과서 12~80쪽」) → 그 쪽 글을 AI 가 소단원별 핵심으로 정리
- **수행평가**(시험 → 수행평가): 내는 날·준비할 것 체크, 오늘 화면에 일주일 안의 것
- **학교 시간표**(설정·예습): 요일·교시별 과목 → 예습 수업 날 자동, 오늘 수업 과목, 내일 수업 과목 바로 예습 넣기
- **목표 등급**(성적): 과목별 목표와 차이, 그래프에 목표선, 최근 4주 공부 시간 비교. **틀린 문항 번호**를 넣으면 자주 틀리는 번호·번호대
- **오답 사진 글자 읽기**: 오답 노트 사진의 글자를 기기 안에서 읽어 「문제」 칸에
- **주간 돌아보기**(기록): 한 주 공부 시간·지난주 비교·한 것·다음 주 일정·한 줄 돌아보기
- **영단어 시험지**: 뜻 쓰기·단어 쓰기·예문 빈칸(쓰기·4지선다), 문제 수 또는 전부, 여러 장으로 나누면 모든 단어가 한 번씩은 나옴, 인쇄, AI 예문 만들기. **단어 연습**: 카드·4지선다·예문 빈칸·듣고 쓰기
- **백지 복습**(복습): 단원 이름만 보고 떠올려 쓰기 → 핵심 내용과 비교 → 빠뜨린 것은 내일 다시
- **문제집 끝내기 예측**: 최근 14일 속도로 끝나는 날, 모자라면 하루 몇 쪽
- **잠·컨디션**: 오늘 화면에서 기록, 기록 화면에서 공부 시간과 비교
- **알림**(설정, 로그인): 정한 시각에 웹 푸시 (VAPID·aes128gcm 직접 구현, worker/push.ts). 서버(Durable Object 알람)가 기기가 미리 계산해 맡긴 글을 보낸다
- **기출·모의고사 풀이**(문제집 → 기출·모의고사 풀이): 옛 수능·모의평가·학력평가·모음집을 푼 날·점수·등급·걸린 시간·틀린 번호. 과목별 점수 흐름, 자주 틀리는 번호, 틀린 번호는 오답 노트로·걸린 시간은 공부 기록으로
- **오답 「나에게 한마디」**: 오답마다 짧은 글을 여러 번 남기고, 다시 풀기 전에 먼저 보여 줌. 「한마디 모아 보기」로 시험 전에 훑어보기
- **메뉴 칸 숨기기**(설정): 안 쓰는 칸은 꺼 두면 메뉴에서 숨김 (자료는 그대로)
- **설정**(맨 위 톱니): 과목·쉬는 날·복습 간격·타이머, 화면 밝기(기기·밝게·어둡게), 백업 파일 내보내기·가져오기

글꼴: Pretendard (OFL-1.1, npm `pretendard`), 사이트에서 직접 내보냄

## 보안

- 로그인 토큰은 HttpOnly·Secure·SameSite=Strict 쿠키로만 (페이지 자바스크립트가 읽을 수 없음), 서버에는 토큰의 SHA-256 만 저장
- 비밀번호 PBKDF2-SHA256 10만 번 + 소금, 8자 이상·쉬운 비밀번호 거부, 틀려도 잠그지 않음 (접속 주소마다 15분에 100번까지만)
- 접속 주소마다 로그인 시도·가입 수 제한, 계정마다 쓰기 횟수 제한
- 바꾸는 요청은 Origin 이 이 사이트인지·JSON 인지 확인 (다른 사이트에서 보낸 요청 거부)
- 비밀번호를 바꾸면 다른 기기 로그인 끊김, 다른 계정이 같은 기기에서 로그인하면 앞 계정 자료를 지우고 받음
- `public/_headers`: CSP(이 사이트 + 글자 인식용 jsdelivr 만), 다른 사이트 안에 넣기 금지, HSTS 등
- 서버 오류 내용은 밖으로 알리지 않음 (Cloudflare 로그에만)

설계: `docs/superpowers/specs/2026-10-23-study-planner-design.md`

## 배포 (Cloudflare Workers, 무료 플랜 가능)

OTT 표시는 TMDB(themoviedb.org)에서 API 키를 받아 같은 방법으로 비밀값 `TMDB_KEY` 에 넣는다 (없으면 표시만 빠진다).

여행 지도(`#/travel/map`)는 카카오맵 JavaScript 키를 비밀값 `kakaomap` 에 넣고, 카카오 개발자 콘솔 › 앱 › 플랫폼 › Web 의 사이트 도메인에 이 사이트 주소(예: `https://life.<계정>.workers.dev`)를 넣어야 지도가 뜬다 (안 되면 OpenStreetMap 으로 대신 보여 준다). 장소 찾기는 카카오 REST 키(`kakaorest` 또는 책 찾기용 `KAKAO_KEY`)를 쓴다.

영화 정보(극장가)를 쓰려면 Cloudflare 대시보드 → Workers & Pages → life → Settings → Variables and Secrets → Add → 종류 **Secret**, 이름 `KOBIS_KEY`, 값에 KOBIS 키. (저장소가 공개라 키를 코드에 넣지 않는다)

`wrangler.jsonc` 그대로 씁니다. Cloudflare 대시보드 → Workers & Pages → 만들기 → 이 GitHub 저장소 연결
(빌드 명령 `npm run build`, 배포 명령 `npx wrangler deploy`). `worker/` 의 로그인·저장 서버(Durable Object + SQLite)와 번역용 Workers AI 연결(`ai` 바인딩)이 같이 올라갑니다.

## 구조

```
src/App.tsx                 맨 위 막대(로그인) + 영역 화면 (src/features/study/Study.tsx 가 주소에 따라 고른다)
src/features/study/         공부 도우미 + 메뉴·설정·저장 (계산: *.ts, 화면: *.tsx, 시험: *.test.ts)
src/features/life/          메인 · 돈 · 취미(농구·영화·게임·음악·여행·독서) · 일기 · 달력 · 통계
src/features/auth/          로그인 · 폰/PC 동기화 · 서버 요청
src/lib/                    IndexedDB · 글자 인식 · 바뀜 알림 · 화면 밝기
worker/                     로그인·저장 서버와 바깥 정보 중계 (/api/*)
scripts/                    서비스 워커 틀(빌드에 씀) · 롤 실시간 도우미(내 컴퓨터에서 직접 실행)
```

## 새로 들어간 것 (요약)

- **시험 공부 자동 계획**: 시험 → 공부 계획. 시험 범위 줄마다 시험 전날까지 날마다 나누고(밀리면 남은 날에 다시), 복습·오답·시험 전날 훑어보기를 넣는다. 하루 시간(평일·주말)·과외 날·쉬는 날·시험 보는 날을 반영, 최근 성적이 낮은 과목은 시간을 조금 늘림. 계산은 `src/features/study/examPlan.ts`.
- **일기 양식**: 오늘 한 것(앱 기록에서 불러오기)·좋았던 것·힘들었던 것·고마운 것·꿈·내일 할 것 중 골라 쓰기, 꿈만 모아 보기.
- **독서**(취미 안), **습관 요일별 달성률**, **농구 혼자 연습**(드릴 17개, 기록으로 약한 부분 찾아 오늘의 연습 짜기).
- **알림**: 보고 싶은 영화 개봉 전날·당일, 내일 빠져나가는 고정 지출, 자주 틀린 단어 퀴즈, 1월 1일 영화 시상식.
- **처음 여는 속도**: 화면마다 코드를 따로 받는다. 첫 화면에 필요 없는 공부 「오늘」·로그인·계정 창·알림 계산은 쓸 때(또는 잠시 뒤 미리) 받는다.
