# 내 공부

문제집·과외 숙제·영단어·오답·공부 시간·할 일·습관을 한곳에서 관리하는 공부 도우미 (한국어, 폰·PC).

## 실행

```bash
npm install
npm run dev        # 개발 서버 (같은 와이파이의 폰에서도 접속 가능)
npm test           # 계산 규칙·보안 시험
npx wrangler dev   # 빌드한 사이트 + 로그인 서버를 이 컴퓨터에서 (npm run build 먼저)
npm run build      # 배포용 빌드 (dist)
```

## 되는 것

- **시험**: 시험 날 + 과목별 시험 날·시험 범위(한 줄씩 체크), 학교 진도 기록. 가장 가까운 시험은 오늘 화면 맨 위에 D-day 로 크게
- **오늘**: 시험 D-day, 과외 숙제, 문제집 오늘 분량, 영단어, 복습, 할 일·습관을 한 화면에. 체크 뒤 「틀린 번호」를 쓰면 오답 노트로
- **문제집 계획**: 목차를 붙여 넣거나(목차 사진 글자 인식도 가능) 시험·마감일을 정하면 하루에 풀 쪽을 나눠 줌. 쉬는 요일·빼는 날짜·과외 날 줄이기, 밀리면 남은 날에 자동으로 다시 나눔, 오늘 분량은 오늘 동안 고정, 너무 많아지면 경고, 달력
- **과외 숙제**: 수업 요일·휴강·보강 → 숙제 마감은 자동으로 다음 수업일, 숙제 쪽은 문제집 계획에서 빠지고 풀면 문제집 진도에도 반영, 질문 메모
- **영단어**: 단어장(Day 계획)·단어 시험(이틀 전까지 새 단어, 전날 전체 복습)·모르는 단어 모음. 단어장 PDF(기기 안에서 PDF.js 로 읽음, 스캔 PDF 는 글자 인식)·붙여넣기·사진으로 넣기, 카드 넘기기·객관식(틀린 보기는 내가 넣은 다른 단어의 뜻에서만)
- **복습**: 오답 노트(사진, 틀린 이유 통계)·암기 카드, 1·3·7·14·30일 간격 상자
- **기록**: 뽀모도로·스톱워치(시작 시각으로 계산해 새로고침해도 맞음), 주간·과목별·최근 4주
- **할 일·습관**: 마감·⭐ 오늘 꼭, 요일별 습관과 연속 일수
- **로그인**(선택): 아이디·비밀번호(이메일 없음). 로그인하면 폰·PC 동기화, 아니면 이 기기에만 저장
  - 계정: 닉네임·비밀번호 바꾸기, 모든 기기에서 로그아웃, 계정 지우기, 로그아웃할 때 이 기기 자료 지우기
- **시험·성적**: 시험 여러 개, 하루 시험(모의고사·수능)과 여러 날 시험(내신: 날짜별 시험 과목), 과목 시험 날은 계획·D-day 에 반영. 지난 성적(내신: 원점수·평균·등급, 모의고사: 원점수·표준점수·백분위·등급)과 과목별 흐름 그래프, 시험 전 4주 공부 시간 비교
- **공부 시간 분석**(기록): 하루 공부 시간 직접 넣기(과목 없이도), 날짜별·주별·요일별·과목별 그래프, 앞 기간과 비교, 연속 공부한 날
- **형광펜 단어**: 단어 넣기 → 「형광펜 사진」: 사진에서 형광펜으로 칠한 영어 단어만 골라(기기 안 글자 인식 + 색 판단) 단어 목록으로, 뜻은 AI 로 채우기(로그인)
- **번역**(메뉴 칸): 한국어 ↔ 영어. 낱말·짧은 말은 사전처럼(품사별 뜻·예문), 글은 자연스럽게, 「직역도 함께」로 의역·직역. 듣기·복사·「모르는 단어 모음」에 넣기. Workers AI `@cf/openai/gpt-oss-120b`(무료 플랜에서 쓸 수 있는 가장 큰 모델), 실패하면 `@cf/google/gemma-4-26b-a4b-it`. 무료 한도(하루 10,000 뉴런)를 지키려고 로그인한 사람만·한 번에 2,000자·한 사람 10분 30번·하루 300번까지
- **예습**: 수업 날·예습할 곳·궁금한 점, 오늘 화면에 오늘·내일 수업 예습, 수업 뒤 이해했는지 체크 → 헷갈린 것은 「다시 볼 것」
- **메뉴 칸 숨기기**(설정): 안 쓰는 칸은 꺼 두면 메뉴에서 숨김 (자료는 그대로)
- **설정**(맨 위 톱니): 과목·쉬는 날·복습 간격·타이머, 화면 밝기(기기·밝게·어둡게), 백업 파일 내보내기·가져오기

## 보안

- 로그인 토큰은 HttpOnly·Secure·SameSite=Strict 쿠키로만 (페이지 자바스크립트가 읽을 수 없음), 서버에는 토큰의 SHA-256 만 저장
- 비밀번호 PBKDF2-SHA256 10만 번 + 소금, 8자 이상·쉬운 비밀번호 거부, 계정마다 5번 틀리면 잠금(점점 길게)
- 접속 주소마다 로그인 시도·가입 수 제한, 계정마다 쓰기 횟수 제한
- 바꾸는 요청은 Origin 이 이 사이트인지·JSON 인지 확인 (다른 사이트에서 보낸 요청 거부)
- 비밀번호를 바꾸면 다른 기기 로그인 끊김, 다른 계정이 같은 기기에서 로그인하면 앞 계정 자료를 지우고 받음
- `public/_headers`: CSP(이 사이트 + 글자 인식용 jsdelivr + Google Fonts 만), 다른 사이트 안에 넣기 금지, HSTS 등
- 서버 오류 내용은 밖으로 알리지 않음 (Cloudflare 로그에만)

설계: `docs/superpowers/specs/2026-10-23-study-planner-design.md`

## 배포 (Cloudflare Workers, 무료 플랜 가능)

`wrangler.jsonc` 그대로 씁니다. Cloudflare 대시보드 → Workers & Pages → 만들기 → 이 GitHub 저장소 연결
(빌드 명령 `npm run build`, 배포 명령 `npx wrangler deploy`). `worker/` 의 로그인·저장 서버(Durable Object + SQLite)와 번역용 Workers AI 연결(`ai` 바인딩)이 같이 올라갑니다.

## 구조

```
src/App.tsx                 맨 위 막대(로그인) + 공부 화면
src/features/study/         공부 도우미 (계산: *.ts, 화면: *.tsx, 시험: study.test.ts)
src/features/auth/          로그인 · 폰/PC 동기화
src/lib/                    IndexedDB · 글자 인식 · 바뀜 알림
worker/                     로그인·저장 서버 (/api/*)
```
